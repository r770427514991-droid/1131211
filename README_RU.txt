w1shq — Android WebView-проект

Важно: в этой среде нет Android SDK/Gradle, поэтому готовый бинарный .apk здесь собрать нельзя.
Этот проект можно открыть в Android Studio и собрать в APK.

Сборка:
1. Установите Android Studio.
2. Откройте папку w1shq_android_project (File → Open).
3. Дождитесь Gradle Sync.
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK будет в app/build/outputs/apk/debug/app-debug.apk.
6. Перенесите APK на Android-телефон и откройте его. Возможно, нужно разрешить установку из этого источника.

В приложении есть мобильный интерфейс генератора. Для настоящей генерации изображений подключите API выбранного провайдера на серверной стороне.
Не помещайте секретный API-ключ непосредственно в HTML/Android-приложение.

ОБЛАЧНАЯ СБОРКА С ТЕЛЕФОНА:
1. Создайте на GitHub новый пустой репозиторий, например w1shq-android.
2. Распакуйте ZIP на телефоне.
3. В репозитории выберите Add file → Upload files и загрузите содержимое папки проекта (включая скрытую папку .github/workflows/android.yml). Удобнее всего делать это в браузере в режиме «Версия для ПК».
4. Нажмите Commit changes. Workflow запускается при push в ветку main.
5. Откройте вкладку Actions → Build w1shq APK → последний запуск.
6. Внизу страницы запуска скачайте artifact w1shq-debug-apk.zip, распакуйте его и установите app-debug.apk на Android.
Если загрузчик файлов телефона не показывает скрытые папки, используйте режим «Версия для ПК» или приложение-архиватор/файловый менеджер, показывающее скрытые файлы.
