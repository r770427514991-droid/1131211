Как получить APK без установки Android Studio (через GitHub Actions)

1. Создайте аккаунт на github.com и новый пустой репозиторий.
2. Загрузите содержимое этой папки в репозиторий (не сам ZIP, а распакованные файлы).
3. Откройте вкладку Actions и выберите workflow “Build w1shq APK”.
4. Нажмите Run workflow (если сборка не запустилась автоматически после push).
5. Когда задача станет зелёной, откройте её и скачайте artifact “w1shq-apk”.
6. Внутри ZIP-артефакта будет app-debug.apk. Перенесите его на Android и установите.

Для загрузки APK на Android может потребоваться разрешить установку приложений из браузера/файлового менеджера.
Это debug APK для личного тестирования, не подписанный релиз для Google Play.
